# Доска публикаций

## Описание проекта

Данный проект разработан в рамках лабораторной работы № 3.

«Доска публикаций» — это интерактивное веб-приложение, позволяющее загружать публикации с сервера и создавать собственные статьи.

Проект разработан с использованием HTML, CSS и JavaScript без применения дополнительных фреймворков.

## Функциональные возможности

- Загрузка пяти публикаций с помощью GET-запроса.
- Создание новых публикаций с помощью POST-запроса.
- Проверка заполнения полей формы.
- Отображение заголовков и текстов публикаций.
- Вывод сообщений об успешных операциях.
- Обработка ошибок HTTP и сетевых сбоев.
- Блокировка кнопок на время выполнения запросов.

## Используемые технологии

- HTML5
- CSS3
- JavaScript
- Fetch API
- Async/Await
- JSON
- HTTP GET и POST

## Инструкция по запуску

1. Скачайте или клонируйте репозиторий.
2. Откройте папку проекта.
3. Убедитесь, что все файлы находятся в одной директории.
4. Откройте файл `index.html` в браузере.

Также можно запустить проект с помощью расширения Live Server в Visual Studio Code.

Для загрузки и создания публикаций необходимо подключение к интернету.

Для работы с публикациями используется JSONPlaceholder:

GET:
https://jsonplaceholder.typicode.com/posts?_limit=5

POST:
https://jsonplaceholder.typicode.com/posts

JSONPlaceholder является тестовым API. Созданные публикации имитируются сервером и не сохраняются постоянно.
